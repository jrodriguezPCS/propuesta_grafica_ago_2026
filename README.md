# Presentaciones

Visor web de diapositivas de **Javier Esteban Rodríguez Medina**.

La pieza actual es la **Propuesta gráfica — redes y campañas** para PCSFORALL:
una lámina vertical de **1920 × 9720 px** que se muestra al **100% del ancho**
del dispositivo (`width: 100%; height: auto`). En un móvil de 390 px de ancho
la altura queda ~1974 px y se recorre con scroll. En un monitor de 1920 px
se ve a tamaño real.

## Ver en línea

https://jrodriguezpcs.github.io/presentaciones/

Si la URL no responde aún: *Settings → Pages → Deploy from a branch → `main` / root*.
